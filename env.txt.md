## Как подключить Telegram-уведомления

1. В Telegram откройте @BotFather.
2. Напишите команду `/newbot` и создайте бота.
3. BotFather выдаст `TELEGRAM_BOT_TOKEN`.
4. Напишите своему новому боту любое сообщение, например: `старт`.
5. Узнайте ваш `TELEGRAM_CHAT_ID`. Самый простой способ — открыть в браузере:
   `https://api.telegram.org/botВАШ_ТОКЕН/getUpdates`
   В ответе найдите `chat` → `id`.
6. Вставьте значения в переменные окружения:
   `TELEGRAM_BOT_TOKEN` и `TELEGRAM_CHAT_ID`.

Важно: токен Telegram-бота нельзя вставлять в обычный HTML/JavaScript на сайте. Он должен храниться только на сервере или в переменных окружения хостинга.

## Запуск локально

```bash
npm install
cp .env.example .env
# заполните .env
npm start
```

После этого сайт будет доступен по адресу:

```bash
http://localhost:3000
```

## Публикация

Самый удобный вариант — Vercel:

1. Загрузите папку проекта на GitHub.
2. Подключите репозиторий к Vercel.
3. В Vercel → Project Settings → Environment Variables добавьте:
   - `TELEGRAM_BOT_TOKEN`
   - `TELEGRAM_CHAT_ID`
4. Нажмите Deploy.

После публикации заявки с сайта будут приходить в Telegram.
